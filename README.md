## Localizando Serviços por Categoria no Microsoft Azure

No portal do Microsoft Azure, é possível localizar rapidamente serviços agrupados por categorias funcionais, facilitando a navegação e escolha conforme suas necessidades. 

Para isso, siga os passos abaixo:

1. Acesse o [Portal do Azure](https://portal.azure.com/).

2. No menu lateral esquerdo, clique em **"Criar um recurso"**.

3. A tela exibirá uma lista de **Categorias** como:  
   - Computação  
   - Redes  
   - Armazenamento  
   - Web  
   - Banco de Dados  
   - Inteligência Artificial + Machine Learning  
   - DevOps, entre outras.

4. Clique em uma categoria para visualizar todos os serviços relacionados.

5. Você também pode utilizar a barra de pesquisa no topo da tela para buscar diretamente por um serviço específico.

Essa organização por categorias ajuda a encontrar com mais facilidade os serviços mais adequados para cada tipo de projeto, seja ele de infraestrutura, dados, IA ou desenvolvimento de aplicativos.
